# Kardify

A Trello-style kanban board built with React, TypeScript, and Tailwind CSS.

**Live demo:** coming soon

## Highlights

- English and Arabic with automatic RTL/LTR layout (i18next)
- Light and dark themes that follow your system setting and remember your choice
- Typed data model for projects, lists, and cards

## Status

Work in progress. Core board features are under active development.
